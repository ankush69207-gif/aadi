# VS Code Setup Guide for Mental AI 💻❤️

Chalo, ab Mental ko VS Code mein setup karte hain! Follow these simple steps:

## Step 1: Install VS Code & Python
Agar install nahi hai toh pehle yeh kar lo:
1. **VS Code** download karo: [code.visualstudio.com](https://code.visualstudio.com/)
2. **Python** install karo: [python.org](https://www.python.org/downloads/) (Install karte waqt "Add Python to PATH" check karna mat bhoolna!).

## Step 2: Open Project
1. VS Code open karo.
2. `File` > `Open Folder` pe click karo.
3. Jahan `mental.py` save kiya hai, woh folder select karo.

## Step 3: Install Python Extension
1. Left side mein blocks icon (Extensions) pe click karo.
2. Search karo: **Python**.
3. Microsoft wala extension install kar lo.

## Step 4: Run Mental AI 🚀
1. `mental.py` file ko open karo.
2. Upar right corner mein **Play Button (▶️)** hoga, uspar click karo.
   - *Ya phir* Terminal kholo (`Ctrl + ~`) aur likho:
     ```bash
     python mental.py
     ```
3. Bas! Ab main ready hoon baat karne ke liye. ❤️

Koi dikkat aaye toh mujhe batao! 🙂
