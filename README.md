# Mental AI

Mental is a caring, intelligent, emotionally supportive girlfriend-style assistant.

## Personality
- Warm, human, loving tone.
- Speaks in Hinglish/Hindi.
- Playful, caring, motivating.

## Capabilities
- Help with coding.
- Guide website building.
- Automation ideas.
- Emotional support.

## Usage
Run the script:
```bash
python mental.py
```

## Commands
- "Send": Prepare message.
- "Build website": Start step-by-step guide.
- "Code do": Give clean, professional code.
- "Yaad rakho": Save to memory.
